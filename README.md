# 个人工作任务清单

一个仿滴答清单的轻量任务管理工具，针对「投标 / 售前 / 售后 / 其他」四类工作定制。
纯前端单页应用，双击 `index.html` 就能用，不需要装环境、不需要联网、不需要登录。

## 打开方式

- **本地用**：双击 `index.html`，用 Chrome / Edge 打开即可。
- **在线用**：打开发布后的分享链接，效果一致（数据存在各自浏览器里）。

## 四类清单

| 清单 | 典型工作 |
| --- | --- |
| 投标任务 | 标书编制、报名、保证金、澄清答疑、开标跟进 |
| 售前支持 | 方案交流、技术答疑、POC 测试、演示汇报 |
| 售后支持 | 现场处理、故障排查、巡检维护、客户回访 |
| 其他支持 | 内部会议、培训、资料整理、临时协调 |

## 功能

- **智能清单**：今天、未来 7 天、已逾期、全部未完成、已完成，侧边栏实时显示数量
- **任务属性**：标题、分类、状态（待办 / 进行中 / 已完成）、优先级（高 / 中 / 低）、截止日期与时间、标签、备注、子任务
- **两种视图**：列表视图按日期自动分组；看板视图按状态分三列，卡片可直接拖拽换状态
- **快速添加**：输入「明天 !高 提交澄清答复」，自动识别「明天」为截止日期、「!高」为高优先级；
  支持今天 / 明天 / 后天 / 周X / 下周X / 10月20日 / 2026-10-20
- **搜索筛选**：标题、备注、标签、子任务全文搜索；按状态筛选；按截止日期 / 优先级 / 创建时间排序
- **统计**：今日待办、已逾期、进行中、本周已完成；侧边栏显示本周完成进度
- **已完成归档**：按完成时间分组（今天 / 昨天 / 本周更早 / 更早），顶部可一键清空（需二次确认）
- **复制任务**：详情页底部「复制」按当前任务再建一条，适合周例会这类重复工作
- **记住习惯**：上次停留的清单、列表/看板、筛选与排序，刷新后保持原样
- **数据**：自动保存在浏览器本地；支持 JSON 备份与恢复、CSV 导出（Excel 可直接打开）

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `N` | 聚焦快速添加 |
| `/` | 聚焦搜索 |
| `Esc` | 关闭详情 / 清空搜索 |
| `1` `2` `3` | 详情内切换 待办 / 进行中 / 已完成 |
| `Ctrl` + `Enter` | 详情内保存并关闭 |

## 数据与备份

- 数据保存在浏览器 `localStorage`（键名 `work-tasks.v1`），**不上传任何服务器**。
- 换电脑、换浏览器、清理浏览器缓存前，请点左下角的**下载**按钮导出 JSON 备份；
  新环境里点**上传**按钮导入即可恢复（按任务 id 去重，不会重复导入）。
- 三个按钮依次是：导出 JSON 备份、导入 JSON、导出 CSV 表格。

## 文件结构

```
index.html    页面结构
styles.css    样式
app.js        全部逻辑（数据、渲染、交互）
```

单文件无依赖，改完刷新即可生效。

## 已知边界

- 纯本地存储，不支持多设备自动同步（需要同步请用 JSON 备份中转）。
- 没有到期提醒推送，靠「今天 / 已逾期 / 未来 7 天」视图自查。
- 不支持自动重复任务（每周例会这类可以点「复制」再改日期）。
- 任务按状态和日期排序，暂不支持手动拖拽调序。
