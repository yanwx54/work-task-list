# 个人工作任务清单

一个仿滴答清单的轻量任务管理工具，针对「投标 / 售前 / 售后 / 其他」四类工作定制。
纯前端单页应用，双击 `index.html` 就能用，不需要装环境、不需要联网、不需要登录。

## 打开方式

- **本地用**：双击 `index.html`，用 Chrome / Edge 打开即可。
- **在线用**：打开发布后的分享链接，效果一致（数据存在各自浏览器里）。

## 四类清单

| 清单 | 典型工作 |
| --- | --- |
| 投标任务 | 标书编制、报名、保证金、澄清答疑、开标跟进 |
| 售前支持 | 方案交流、技术答疑、POC 测试、演示汇报 |
| 售后支持 | 现场处理、故障排查、巡检维护、客户回访 |
| 其他支持 | 内部会议、培训、资料整理、临时协调 |

## 功能

- **日历首页**：主流月视图——整表细线网格、周末浅底、今天圆形高亮，
  日期数字右侧同行显示**农历**（初一显示月名，廿/除夕/春节/中秋/国庆等节日红色高亮，悬停看完整农历），
  任务以分类色圆点 + 浅色胶囊铺在截止日（时间前缀，每格最多 4 条，多余的点「还有 N 项」看），
  拖动胶囊可改日期（带撤销），点日期看下方当天清单，空日期一键添加；
  重复任务完成本期后，日历会先铺出未来几期的虚线预览
- **今天清单**：列出**所有未完成任务**，按 已逾期 / 今天 / 明天 / 未来 7 天 / 更晚 / 没有日期 分组，
  今天已完成的单独放在末尾，不会漏事
- **智能清单**：今天、未来 7 天、已逾期、全部未完成、已完成，侧边栏实时显示数量
- **任务属性**：标题、分类、状态（待办 / 进行中 / 已完成）、优先级（高 / 中 / 低）、截止日期与时间、标签、备注、子任务、实际耗时
- **重复任务**：每天 / 每周 / 每两周 / 每月 / 每年，完成本期自动生成下一期，子任务重置，周例会、月度巡检不用手建
- **批量操作**：悬停出现选择框，Shift 连选；批量完成、改分类、改日期、归档
- **两种视图**：列表视图按日期自动分组；看板视图按状态分三列，卡片可直接拖拽换状态
- **手动排序**：排序切到「手动排序」后，列表项可直接拖动调整顺序，松手即保存
- **快速添加**：输入「明天 !高 提交澄清答复 #国网」，自动识别日期、优先级与标签；
  粘贴多行文本回车即批量添加；支持今天 / 明天 / 后天 / 周X / 下周X / 10月20日 / 2026-10-20
- **搜索筛选**：标题、备注、标签、子任务全文搜索，命中词高亮；按状态筛选；按截止日期 / 优先级 / 创建时间排序
- **分类统计**：按分类看任务量占比、完成率、耗时占比，支持本周 / 本月 / 全部切换，一眼看出工作重心
- **归档**：删除不丢数据，先进「归档」，可恢复，也可彻底删除
- **每日提醒**：开启后每天 9 点后首次打开页面，用系统通知提醒今日待办与逾期任务
- **打印周计划**：一键生成 A4 纵向周计划表，按周一到周日列出任务，可打印或存 PDF
- **已完成归档**：按完成时间分组（今天 / 昨天 / 本周更早 / 更早），顶部可批量归档
- **复制任务**：详情页底部「复制」按当前任务再建一条（含重复设置），适合临时要办两遍的活
- **暗色模式**：左下角月亮 / 太阳按钮，自动（跟随系统）/ 浅色 / 深色 三档，选择会记住
- **记住习惯**：上次停留的清单、列表/看板、筛选与排序、主题，刷新后保持原样
- **数据**：自动保存在浏览器本地；JSON 备份导入按「更新时间」智能合并（新者胜，不会回退也不会重复）
- **CSV 导出**：可选时间范围（全部 / 本周 / 本月 / 上月 / 自定义起止）与时间口径（完成 / 截止 / 创建 / 智能），
  实时预览条数，可勾选是否含归档，Excel 直接打开
- **自动备份**：每天首次打开自动存一份快照（保留最近 3 天），主数据损坏时自动兜底，
  也可以在「使用说明」里手动恢复到某天的快照
- **多标签页同步**：同一浏览器开多个页面，一边改动另一边实时更新，不会互相覆盖丢数据
- **日常待办**：和任务分开的每日零碎事清单（早会、日报、巡检这类）——选日期写一句，回车加一条并自动带时间，
  圆圈勾选完成、点正文就地改、删除可撤销、支持搜索；**会显示在日历对应日期上**
  （灰色虚线圆点色条，点一下直接勾掉、拖到别处就是挪天）；
  只存本机，**不参与 JSON / CSV 导出**

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `N` | 聚焦快速添加 |
| `/` | 聚焦搜索 |
| `Esc` | 关闭详情 / 取消选择 / 清空搜索 |
| `1` `2` `3` | 详情内切换 待办 / 进行中 / 已完成 |
| `Ctrl` + `Enter` | 详情内保存并关闭 |
| `↑` `↓` | 列表中上下移动焦点行 |
| `Enter` | 打开焦点行详情 |
| `Space` | 完成 / 取消完成焦点行 |
| `S` | 选中 / 取消选中焦点行（配合底部操作条批量处理） |
| `Delete` `Backspace` | 归档焦点行（归档区里为彻底删除） |
| `Shift` + 点击选择框 | 连选一段任务 |
| 粘贴多行到快速添加 | 回车批量添加 |

## 数据与备份

- 数据保存在浏览器 `localStorage`（任务 `work-tasks.v1`，日常待办 `work-tasks.daily.v1`），**不上传任何服务器**。
- 换电脑、换浏览器、清理浏览器缓存前，请点左下角的**下载**按钮导出 JSON 备份；
  新环境里点**上传**按钮导入即可恢复。导入按任务 id 合并：同一条取更新时间较新的版本，
  已彻底删除的不会复活。
- **日常待办不进 JSON / CSV 导出**（只留在本机、只随每日自动快照一起备份），
  所以导出文件专门作为任务数据的干净载体；需要带走记录时请自行复制。
- 同一浏览器开多个标签页也没关系：任何一边的改动另一边会实时同步（任务和日常待办都同步）。
- 左下角一排按钮依次是：导出 JSON 备份、导入 JSON、导出 CSV 表格、打印周计划、每日提醒、主题切换、使用说明。

## 文件结构

```
index.html    页面结构
styles.css    样式
app.js        全部逻辑（数据、渲染、交互）
```

单文件无依赖，改完刷新即可生效。

## 已知边界

- 纯本地存储，不支持多设备自动同步（需要同步请用 JSON 备份中转，导入会自动合并）。
- **提醒需要页面处于打开状态**（哪怕是后台标签页）。页面完全关闭后浏览器不会推送，
  这是纯前端应用的限制，要后台推送得配 Service Worker + 服务端。
- 重复任务是「完成本期 -> 生成下一期」，不是预先铺满日历；删除下一期不会影响本期，
  本期再完成时会重新生成。
- 耗时需要手动填写，不会自动计时。
- 自动快照只保留最近 3 天，且存在同一个浏览器里；换设备或清缓存前请仍用 JSON 导出。

## 其它
