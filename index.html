使用说明

四类工作清单

  • 投标任务：标书编制、报名、保证金、澄清答疑、开标跟进
  • 售前支持：方案交流、技术答疑、POC 测试、演示汇报
  • 售后支持：现场处理、故障排查、巡检维护、客户回访
  • 其他支持：内部会议、培训、资料整理、临时协调

今天首页

「今天」会列出所有还没完成的任务，按 已逾期 / 今天 / 明天 / 未来 7 天 / 更晚 / 没有日期 分组， 今天已完成的单独放在最下面。这样打开就是一张完整的工作台，不会漏事。

分类统计

看各类工作的任务量占比、完成率、耗时占比。耗时需要在任务详情里填「实际耗时」才有数据， 没填的不计入。支持按 本周 / 本月 / 全部 切换。

归档

点删除不会真的删，任务会进「归档」，随时能恢复。归档里再点删除才是彻底删除。

每日提醒

点左下角铃铛开启。开启后每天 9 点后第一次打开页面，会用系统通知提醒今日待办和逾期任务，一天只提醒一次。 注意：页面关着的时候不会推送，这是纯本地应用的限制。

打印周计划

点左下角打印机图标，直接生成 A4 纵向的本周计划表，按周一到周日列出每天的任务， 可以打印或存成 PDF 带去开会。

数据存在哪

全部数据保存在本机浏览器（localStorage），不上传服务器。换电脑或清缓存前，请用左下角 下载 按钮导出 JSON 备份，需要时用 上传 恢复。

自动备份

每天首次打开会自动存一份快照，保留最近 3 份。

小技巧

  • 列表里点左侧圆圈即可完成任务；点标题打开详情。
  • 看板视图可以直接把卡片拖到另一列，状态随之改变。
  • 排序切到「手动排序」后，可以拖动任务自己排顺序，松手即保存。
  • 快速添加支持「明天 / 后天 / 周五 / 下周三 / 10月20日」这类词，会自动识别成截止日期。
  • 快速添加里加 !高 / !中 / !低 可以直接设优先级，例如「明天 !高 提交标书」。
  • 详情页底部「复制」可以按当前任务再建一条，适合每周例会这类重复工作。
