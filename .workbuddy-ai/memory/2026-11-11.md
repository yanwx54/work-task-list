## 第七轮：七项改进迭代

用户问「还能怎么改进」，我通读了 app.js(2000+行)/styles.css(1178行)/README/两轮日志后给出分层建议，
用户选了「开工」，本轮做完 7 项（自检 48 项断言全通过，无控制台错误）：

1. **修复多标签页数据互踩（安全隐患，最优先）**
   原来 `save()` 是整包覆盖 localStorage，两个标签页编辑，后保存的会把先保存的一口吞掉。
   现在：save 前先与存储合并；监听 `storage` 事件实时同步到 DOM；彻底删除写
   `purged` 墓碑（`{id: 删除时间}`），删除能同步且旧备份/旧页面不会让任务"复活"。
   合并规则：同 id 取 `updatedAt` 新者；本地有远端没有且无墓碑 = 本机新增，保留。
2. **重复任务自动生成**：任务加 `repeat`（每天/每周/每两周/每月/每年，抽屉里选择），
   完成本期（任何路径：勾选、看板拖到已完成、状态按钮、快捷键 1-3、批量完成）自动建下一期，
   子任务重置。**逾期补做时下一期跳过今天之前的周期**，不会继续挂着逾期。
   `nextId` 链防"取消完成→再完成"刷任务；月/年按月末对齐（1月31日→2月28日）。
3. **批量选择 + 批量操作**：行悬停左侧出现选择框，Shift 连选；底部吸附操作条
   （完成/改分类/改期到明天/选日期/归档，归档视图里是彻底删除）。Esc 退出。只在列表视图。
4. **键盘导航**：↑↓ 移焦点（红圈高亮），Enter 打开、空格完成、S 选中、Del/Backspace 归档；
   Esc 顺序改为 帮助弹窗→抽屉→取消选择→清搜索。
5. **暗色模式**：styles.css 110+ 处写死颜色全部 token 化，新增 `[data-theme="dark"]` 覆盖块；
   侧栏加 自动→浅色→深色 三档轮转按钮（`prefers-color-scheme` 跟随，prefs 记 `theme`）。
   JS 内联的浅底色板（分类/优先级徽章）靠 `color-mix(in srgb)` 兜底，旧浏览器忽略即回退原样。
   打印区保留硬编码（纸张必须白底黑字），`color-scheme` 同时翻原生 date/time 控件。
6. **快速添加增强**：支持 `#标签`；粘贴多行回车批量添加（input 换 textarea，
   Enter 提交、Shift+Enter 换行，行数自适应）；顺手修了 ensureNewVisible——
   搜索中新任务不命中关键词会"加了看不见"，现在会清掉搜索。
7. **导入合并**：JSON 导入从"跳过已存在"改为按 updatedAt 新者胜 + 尊重墓碑，
   跨设备中转备份不再丢更新、不回退、不复活。CSV 加「重复」列，复制任务继承 repeat。

**周边**：README/帮助弹窗同步（快捷键表、新功能段落、已知边界改写）；MEMORY.md 补 4 条设计决定。

**踩坑**：验证脚本走 file:// 时 storage 事件测不到同步 → 改起本地 http server；
