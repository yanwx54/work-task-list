## Project10 个人工作任务清单（新建）

**做了什么**：从零做了一个仿滴答清单的任务管理 Web 应用，针对用户的四类工作定制：
投标任务 / 售前支持 / 售后支持 / 其他支持。

**技术选型**：纯前端单页（index.html + styles.css + app.js），零依赖、零构建。
数据存 localStorage（键 `work-tasks.v1`）。选纯前端而不是 Project09 那种 Flask+SQLite，
是因为要能双击打开、也要能发布成静态链接，不需要起服务。

**已实现**：
- 智能清单：今天 / 未来 7 天 / 已逾期 / 全部未完成 / 已完成，侧栏实时计数
- 任务属性：分类、状态（待办/进行中/已完成）、优先级、截止日期时间、标签、备注、子任务
- 列表视图（按日期自动分组）+ 看板视图（三列，HTML5 拖拽换状态）
- 快速添加支持自然语言日期：今天/明天/后天/周X/下周X/10月20日/2026-10-20
- 搜索、状态筛选、四种排序、四个统计卡、本周完成进度条
- JSON 备份导出/导入（按 id 去重）、CSV 导出（带 BOM，Excel 直接打开）
- 快捷键 N / / / Esc / 1-3 / Ctrl+Enter；响应式（手机端侧栏抽屉化）

**自检**：用 playwright-core + 本机 chromium 跑了 12 项交互测试，全通过、无控制台错误。
测试中发现并修掉一个真 bug：toast 的「撤销」按钮因为父级 `pointer-events: none` 点不动，
改成 `.toast button { pointer-events: auto }`。
另外修了移动端顶栏被挤压导致标题竖排的问题（topbar 改 flex-wrap，工具条换行）。
